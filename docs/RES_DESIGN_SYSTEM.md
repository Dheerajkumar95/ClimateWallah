# RES Design System (Source of Truth)

Colours: primary green `#009C72`, accent `#00C896`, dark navy `#101827`, secondary navy `#1C2738`, mint `#EAFBF4`, light grey `#F5F7F8`, border `#E2E7EC`, Scope1 `#E52427`, Scope2 `#F59E0B`, Scope3 `#079B70`.
Existing brand: deep forest green already in use for the public site — portal reuses the green family and navy for app chrome.
Type: Outfit (body) + Cormorant Garamond (display) already in project; portal uses Outfit/Inter for data density.
Layout: content 1200–1440px, card radius 14–20px, header 72–80px, generous vertical spacing, white bg + soft grey sections + mint highlights, subtle borders + light shadows, minimal smooth motion, reduced-motion support.
Portal shell: compact white top bar + responsive sidebar (not the public marketing header).
