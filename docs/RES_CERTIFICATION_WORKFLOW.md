# RES Certification Workflow (Source of Truth)

Roles: Client (self-register+OTP), Reviewer (admin-created), Admin (single seeded).
Project status flow: Draft → Client Submitted → Admin Triage → Reviewer Assigned → Preliminary Review → Changes Requested → Client Resubmitted → Reviewer Recommended → Forwarded to Admin → Admin Review → Approved → Certified / Rejected. (Phase‑1 foundation implements Draft→Submitted→Assigned; deeper review states are next.)

Three score levels: Client Claimed → Reviewer Recommended → Admin Final. Client never enters final points. Reviewer never issues certification. Admin awards final + uploads official certificate record for real certification.

Sequential client wizard: only current section editable; next unlocks after current section's mandatory items are answered+saved; completed sections editable until final submit; auto-save; versioned snapshot on submit.

Disclaimer until official record exists: "RES Internal/Preliminary Assessment — not an official IGBC certification."
